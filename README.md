# Exercícios de Programação

Repositório com exercícios de C e C++ desenvolvidos durante o curso técnico.

## 📚 Conteúdo

- **Vetores** – manipulação, busca, ordenação
- **Classes e objetos** – conceitos de POO em C++
- **Herança** – classes base e derivadas

## 🛠️ Como compilar e executar

**C:**
```bash
gcc arquivo.c -o programa
./programa
```

**C++:**
```bash
g++ arquivo.cpp -o programa
./programa
```

## 🎯 Objetivo

Praticar lógica de programação e fixar os conceitos vistos em aula.
